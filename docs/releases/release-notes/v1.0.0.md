## Highlights

The first playable release of the Bust-A-Move clone: a complete arcade
bubble-shooter on the web.

- **Hex-grid board** with offset rows, wall bounce aiming, and a shot preview
  queue.
- **Match-3 popping, chain reactions, and detached-cluster drops** — clusters
  that lose their connection to the ceiling fall and score separately.
- **Wall descent** on a shot-driven cadence, with lives lost when the wall
  reaches the cannon line.
- **Five difficulty configs** with endless progression above level 5.
- **Juice pass:** particle bursts, score popups, screen shake, cannon recoil, and
  a projectile trail.
- **Responsive canvas** with viewport constraints and mobile support.
- **MVVM architecture** — pure-Dart domain, ViewModels, feature folders, and
  headless engine tests.

## Known issues

### #95 — Web icons ship as base64 text; one manifest icon 404s

- **Severity:** low — presentation only, gameplay unaffected.
- **What a player sees:** a broken favicon and install icon, one failed request
  on every load, and no "Install app" prompt.
- **Status:** **fixed on `develop`**, not part of this release.
- **Fix:** PR [#97](https://github.com/y0n1/bust_a_move_clone/pull/97) —
  `fix(web): ship real PNG icons and a valid manifest` (`50121d4`). Decodes the
  four files to real PNGs, removes the `Icon-maskable-512.png` manifest entry
  that pointed at a file which never existed, and replaces the deprecated
  `apple-mobile-web-app-capable` meta tag.
- **Detection:** `test/web_assets_test.dart`, added by the fix. It fails 3/3 on
  this release's commit, so the defect cannot return silently.
- **Ships in:** the next release.

### Other limitations

- No accessibility audit, performance budget, or cross-browser evidence has been
  produced yet — tracked as QE-3, QE-4, and QE-5.
- The critical-path smoke suite is not yet wired into CI; post-deploy
  verification is manual — tracked as OPS-4.
