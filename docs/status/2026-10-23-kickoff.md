## 7. What happens next

1. Project Manager confirms **Ready** against the Definition of Ready and keeps
   the board ordered by priority and rank.
2. Developers create one worktree per task and implement in rank order.
3. QE verifies each PR and writes the verdict; **every defect found is filed to
   the board immediately**.
4. Project Manager triages each defect; Product Manager records whether it is
   **must-fix for the version** or **postponed**.
5. The team merges once CI is green and QE has a verdict.
6. Project Manager owns the version bump, tag, and release notes; DevOps deploys
   and verifies production.
7. Project Manager reports progress in `docs/status/`.
